Ajuda: Perfil

-----Contingut d'ajuda -----------

DESCRIPCIÓ

El mòdul Perfil és per gestionar camps de perfil d'usuari personalitzats.

INSTAL·LA/DESINSTAL·LA

No cal mesures especials, seguiu el procés d'instal·lació estàndard: extreu la carpeta /profile al directori ../modules. Instal·leu el mòdul mitjançant Admin -> System Module -> Modules.

Les instruccions detallades sobre la instal·lació dels mòduls estan disponibles a la pàgina Manual d'operacions XOOPS

INSTRUCCIONS DE FUNCIONAMENT

Per configurar aquest mòdul cal:

  • Configureu les vostres preferències per al mòdul (vegeu 'Preferències') i opcionalment el bloc Perfil si voleu utilitzar-lo (vegeu 'Blocs').
  • Editeu les categories existents o afegiu-ne de noves.
  • Editeu els camps existents o afegiu-ne de nous. Aquí podeu especificar quins camps seran visibles en quina categoria i si seran visibles durant el registre de l'usuari.
  • Definiu l'ordre dels passos de registre.
  • I, finalment, podeu establir permisos per a camps individuals: quins són editables i quins es poden cercar.

Mesures anti-spam

Per minimitzar els registres de correu brossa, feu el següent:

  • aneu al mòdul Protector d'Administració, aneu a Preferències i, a continuació, a la part inferior, en aquesta opció: "Atura el correu brossa del fòrum" Comprova les dades POST amb els spammers registrats a la base de dades www.stopforumspam.com.
    Estableix-lo a "Prohibir la IP (sense límit)"

  • a /class/captcha/config.php, assegureu-vos que el mode estigui definit com a "text":

    retorna $config = array(
    'disabled' => fals, // Desactiva CAPTCHA
    'mode' => 'text', // mode predeterminat, podeu triar 'text', 'imatge', 'recaptcha' (requereix la clau API)
    'name' => 'xoopscaptcha', // nom captcha
    'skipmember' => true, // Omet la comprovació CAPTCHA dels membres
    'maxattempts' => 10, // Màxim d'intents per a cada sessió
    );

  • Al mòdul Perfil, aneu a Administrador i al pas bàsic situat a:
    /modules/profile/admin/step.php?id=1
    defineix "Desa després de l'aturada" a "No"


  • A les preferències del perfil, configureu l'opció "Utilitza Captcha després del segon pas de registre" a "Sí" (és el valor predeterminat)
