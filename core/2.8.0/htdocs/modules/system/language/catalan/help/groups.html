Ajuda: Grups

Descripció

XOOPS incorpora un sistema de registre de membres: opcionalment podeu demanar que la gent es registri al vostre lloc per tenir accés a determinades àrees o funcions. Per exemple, la majoria de llocs requereixen que la gent s'uneixi abans que se'ls permeti contribuir amb notícies o publicar missatges als fòrums.
Els drets d'accés i administració a un lloc web de XOOPS s'estableixen mitjançant un sistema de permisos flexible basat en "grups d'usuaris". Els grups predeterminats inclouen usuaris anònims, membres registrats i administradors web, però, per descomptat, podeu definir tants grups com necessiteu per gestionar el vostre lloc. Cada grup pot rebre un conjunt únic de drets d'accés que regeixin:

- Quins blocs es poden veure
- A quins mòduls es pot accedir
- Quins mòduls es poden administrar
- Quins aspectes de l'administració del sistema es poden modificar

Podeu canviar el nom d'aquests grups per defecte, però no podeu suprimir-los. També es poden configurar i definir altres grups d'usuaris tal com es comentarà més endavant.

També es poden crear grups personalitzats mitjançant la pàgina d'administració de grups.
