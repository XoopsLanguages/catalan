Instal·lant XOOPS

Primera instal·lació

Pròleg:

XOOPS és un codi obert Sistema de publicació web orientat a objectes escrit en PHP. És una eina ideal per desenvolupament de petits i grans llocs web dinàmics de comunitats, portals intraempresarials, portals corporatius, weblogs i molt més.

XOOPS es publica sota els termes del GNU General Public License (GPL) versió 2 o superior, i és gratuït d'utilitzar i modificar. La redistribució és gratuïta sempre que compleixi els termes de distribució de la GPL.

Requisits

  • Servidor WWW (Apache, NGINX, IIS, etc.)
  • PHP 8.2 o superior, 8.4+ recomanat
  • MySQL 5.7 .8 o superior, es recomana MySQL 8.4.5+

Abans d'instal·lar

  1. Configura correctament el servidor WWW, PHP i el servidor de bases de dades.
  2. Prepareu una base de dades per al vostre lloc XOOPS.
  3. Prepareu el compte d'usuari i concediu-li l'accés a la base de dades.
  4. Feu que els directoris i els fitxers siguin escrivibles: %s
  5. Per consideracions de seguretat, us recomanem molt que moveu els dos directoris següents fora de arrel del document i canvieu els noms de les carpetes: %s
  6. Crea (si encara no està present) i fes que els directoris es puguin escriure: %s
  7. Activa la cookie i JavaScript del teu navegador.

S'està instal·lant localment

Si esteu executant un entorn local per al desenvolupament o la prova, assegureu-vos que teniu l'anterior requisits complerts. Un cop fet això, copieu el contingut del fitxer htdocs Estat (del XOOPS fitxer de distribució) a la ruta del document arrel del vostre entorn web. Un cop copiats els fitxers allà, podeu iniciar la instal·lació dirigint el vostre navegador a "http://yoursite.com". Això iniciarà el procés d'instal·lació.

Instal·lació en una plataforma allotjada

Si esteu executant en un entorn allotjat, desempaqueteu els fitxers XOOPS localment o al servidor si teniu accés al shell (és a dir, SSH). Un cop fet, assegureu-vos de moure o copiar tots els fitxers XOOPS del fitxer htdocs Estat al directori web arrel (el vostre proveïdor sol proporcionar aquesta ubicació amb indicacions). Un cop copiats els fitxers allà, podeu iniciar la instal·lació apuntant al vostre navegador "http://yoursite.com". Això iniciarà el procés d'instal·lació.
